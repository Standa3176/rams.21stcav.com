## Design system — concrete tokens

### Colours (Tailwind extension)

```js
colors: {
  // Neutrals — cool slate scale (already exists; explicit for clarity)
  ink:     '#0F172A',  // slate-900 — headings + primary text
  body:    '#334155',  // slate-700 — body text
  muted:   '#64748B',  // slate-500 — captions, secondary
  hairline:'#E2E8F0',  // slate-200 — borders
  canvas:  '#F8FAFC',  // slate-50  — page background
  card:    '#FFFFFF',  // pure white — surface
  // Accent — indigo (tier-one SaaS standard)
  brand: {
    50:  '#EEF2FF',
    100: '#E0E7FF',
    500: '#6366F1',
    600: '#4F46E5',   // primary accent
    700: '#4338CA',
    800: '#3730A3',
  },
  // Semantic status
  success: '#059669',  // emerald-600
  warning: '#D97706',  // amber-600
  danger:  '#DC2626',  // red-600
  info:    '#0284C7',  // sky-600
}
```

**Legacy teal (`#01889F`)** — retained inside `resources/views/pdf/` templates and `config/rams.php`. UI moves off it entirely.

### Typography

- **Family:** Inter, self-hosted via `@fontsource/inter` (weights 400 / 500 / 600 / 700).
- **Ramp:** `text-xs` (12px) / `text-sm` (14px, body default) / `text-base` (16px, larger body) / `text-lg` (18px, subheadings) / `text-xl` (20px) / `text-2xl` (24px, page titles) / `text-3xl` (30px, hero).
- **Weights:** 400 body, 500 UI labels, 600 subheadings, 700 headings + button text.
- **Feature settings:** `font-feature-settings: 'cv11', 'ss01', 'ss03'` for the InterVariable-look on `body`.
- **Line-height:** 1.5 body, 1.25 headings.
- **Tabular numerals** on data-heavy views: add a `.tabular-nums` helper to tables.

### Spacing scale

Tailwind default 4pt scale is retained. **Enforce** rather than extend — no more one-off `px-[13px]`. Standard uses: `space-y-6` between major sections, `p-6` inside cards, `gap-4` in toolbars.

### Radii

- `rounded-md` (6px) — inputs, buttons, badges (standard).
- `rounded-lg` (8px) — cards, panels.
- `rounded-xl` (12px) — modals, hero cards.

### Shadows

Custom-tuned for tier-one restraint (Tailwind defaults are too heavy for data-dense UI):

```js
boxShadow: {
  'card':      '0 1px 2px 0 rgb(15 23 42 / 0.04), 0 1px 3px 0 rgb(15 23 42 / 0.06)',
  'card-hover':'0 4px 6px -1px rgb(15 23 42 / 0.08), 0 2px 4px -2px rgb(15 23 42 / 0.06)',
  'popover':   '0 10px 15px -3px rgb(15 23 42 / 0.10), 0 4px 6px -4px rgb(15 23 42 / 0.08)',
  'inset-focus':'0 0 0 3px rgb(79 70 229 / 0.20)',  // brand-600 @ 20%
}
```

### Component patterns

- **Buttons:** primary = solid brand-600 → brand-700 hover, `rounded-md`, `px-4 py-2`, `text-sm font-semibold`, focus ring `shadow-inset-focus`. Secondary = white bg, `border border-hairline`, `text-body`. Danger = solid `red-600`. Ghost = transparent, `hover:bg-canvas`.
- **Cards:** `bg-card border border-hairline rounded-lg shadow-card p-6`. Hover-clickable variant adds `hover:shadow-card-hover transition`.
- **Inputs:** `border border-hairline rounded-md px-3 py-2 text-sm text-ink placeholder:text-muted focus:ring-2 focus:ring-brand-600 focus:border-brand-600`.
- **Badges:** `inline-flex items-center rounded-md px-2 py-0.5 text-xs font-medium` with tinted backgrounds per status (`bg-brand-50 text-brand-700`, `bg-emerald-50 text-emerald-700`, etc.).
- **Tables:** hairline dividers, `text-sm`, header `bg-canvas text-muted uppercase tracking-wide text-xs`, rows `hover:bg-canvas`.
- **Page headers:** `text-2xl font-semibold text-ink` title + `text-sm text-muted` description, action buttons right-aligned.

## Rollback plan

- **Foundation only breaks:** revert Task 1 commit — Tailwind config and font import isolated.
- **Component change causes visual regression:** revert Task 2 commit — component APIs unchanged so nothing else moves.
- **Anchor screen looks worse:** revert Task 3 or 4 commit independently.

Each task is its own commit. Rollback is a single `git revert <hash>`.
