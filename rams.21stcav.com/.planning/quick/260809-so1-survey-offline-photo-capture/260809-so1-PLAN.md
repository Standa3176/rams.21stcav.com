# Quick Task 260809-so1 — Survey offline-first photo capture (shared partial seed)

## Problem
The Site Survey wizard's `uploadPhoto()` (`surveys/show.blade.php:2131-2162`) posts the **raw File** straight to
`POST /survey/{token}/rooms/{roomId}/photos` inside a `try {} catch (_) {}`. On flaky 4G or offline the photo is
**silently dropped**, and iPhone **HEIC** files are rejected by the server image validator + Claude vision OCR.

The Worksheet already solved both problems (task 260603-eha: `window.OfflineQueue` IndexedDB queue; task 260504-ktt:
`convertToJpegBlob` HEIC→JPEG canvas re-encode). This task **ports that capability to the Survey** by extracting a
**shared inline Blade partial** (the seed of a future shared `21stcav/engineer-capture` package) and consuming it from
the Survey **only**. The Worksheet is left untouched — its migration onto the shared partial is a deferred package step.

## Constraints / decisions
- These pages ship **inline `<script>`, no `@vite`** — so the shared unit is a Blade `<script>` partial exposing
  `window.*` globals (matches the 260603-eha convention), not a `resources/js/*.js` ESM module.
- Generalise the queue: each record carries its **own `endpoint` + generic `fields`** (SCC `pmvPhotoQueue` design) so the
  same module serves the Survey (`/survey/{token}/rooms/{id}/photos`, `category`) and, later, the Worksheet.
- DB name **`engineer-capture`** (v1, store `pending_uploads`) — distinct from the Worksheet's `engineer-worksheet` DB so
  the two queues never surface each other's rows.
- Outcome classification: `2xx → delete`; `413/415/422 → terminal discard`; `network/5xx/offline → keep + bump
  attemptCount`, max-retry marker at `>= 3`. Auto-drain on `online` + 60s interval + on load.
- **Chip UX deviation (documented):** a **fixed** always-visible chip (bottom-right) rather than an inline container inside
  step 3 — the wizard hides inactive steps, so an inline chip would vanish when the engineer advances to step 4+. Same
  intent (surface pending count + Retry), better visibility. `window.mountOfflineChip(target)` is still exposed for
  explicit placement.
- DO NOT touch: `savePhotoCaption` (PATCH), the 6 `x-survey.photo-upload` components, `components/survey/photo-upload.blade.php`
  (`accept="image/*"` stays; **no `capture=`** — it would remove the photo-library option), the text autosave path
  (`autosave()/autosaveSite()` → `/survey/{token}/step-save`), and the entire Worksheet blade.

## Tasks

### Task 1 — Shared partial `resources/views/partials/_engineer-offline-capture.blade.php`
- files: resources/views/partials/_engineer-offline-capture.blade.php (new)
- action: Inline `<script>` (pure JS, no Blade vars) defining and exposing on `window`:
  `convertToJpegBlob(file,maxSide=2400,quality=0.92)` (copied faithfully from the Worksheet), `convertToJpegBlobSafe`
  (try→raw-file fallback), `OfflineQueue` (IndexedDB `engineer-capture`/`pending_uploads`; record
  `{token, endpoint, blob, originalName, mime, fields, attemptCount, lastError, capturedAt}`; `enqueue/list/count/remove/
  drain/subscribe`), and `mountOfflineChip(target)`. Auto-drain on `online`+60s+load; self-mount a fixed chip. All DOM via
  `textContent` (XSS discipline). Optional `window.showToast` guarded by `typeof`.
- verify: `grep -c "window.OfflineQueue" partial` ≥1; `grep "engineer-capture" partial`; `grep "convertToJpegBlobSafe" partial`.
- done: partial exists, exposes the three globals, uses a distinct IndexedDB name.

### Task 2 — Wire the Survey wizard
- files: resources/views/surveys/show.blade.php
- action: `@include('partials._engineer-offline-capture')` immediately before `</body>` (line ~2247). Rewrite
  `uploadPhoto(roomId, input)`: `convertToJpegBlobSafe(file)` → build `endpoint`+`fields:{category}` → if `navigator.onLine`
  attempt immediate upload (blob as `photo`, `category`), preserving the EXACT Alpine success push
  `{ id, type:res.category??category, caption:res.caption??'', file_path:res.url??'' }`; on offline OR failure
  `OfflineQueue.enqueue(...)`. Keep `input.value=''`. Comment the background-drain/reload caveat.
- verify: `uploadPhoto` calls `convertToJpegBlobSafe` + `OfflineQueue.enqueue`; success push shape intact; `@include` present.
- done: Survey queues offline photos + re-encodes HEIC; step-save + caption paths unchanged.
