<objective>
Add a project-level "Engineer Reference Files" feature so staff can upload plans / drawings / connection diagrams / cable schedules to a Project, and the on-site engineer can open them from BOTH the public worksheet link AND the public survey link.

Purpose: Today the engineer's only on-site reference is the per-room survey photos and the kit list — there is nowhere to attach a site plan PDF, a CAD/DWG drawing, an Excel cable schedule, or a Word method statement that the engineer needs in their hand on the day. This adds the missing channel without rebuilding the documents pipeline (these are uploaded artifacts, not generated ones).

Output: 1 migration, 1 model, 1 service, 1 admin controller, 2 new public download endpoints (worksheet + survey), 1 shared Blade drawer partial, 1 admin upload card partial, ~6 routes, ~17 tests across 5 test files. No changes to the RAMS / O&M / Worksheet / Cable generators (D-LOCK preserved — RamsRenderRegression byte-equivalence stays green by construction since this feature never touches those services).

    sanitiseFilename pseudocode:
    1. $name = trim($name);
    2. $ext = strtolower(pathinfo($name, PATHINFO_EXTENSION));
    3. $base = pathinfo($name, PATHINFO_FILENAME);
    4. $base = str_replace(['..', '/', '\\', chr(0)], '_', $base);
    5. $base = preg_replace('/[\x00-\x1F\x7F]/u', '_', $base);
    6. $base = preg_replace('/_{2,}/', '_', $base);
    7. $base = preg_replace('/\.{2,}/', '.', $base);
    8. $base = substr($base, 0, 100);
    9. if ($base === '' || $base === '_') $base = 'file';
    10. return $base . '.' . $ext;
