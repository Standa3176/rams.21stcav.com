<objective>
Extend `app/Services/QuoteParserService.php` to recognise the second QuoteWerks template variant — the **priced "ram" template** that uses short single-character-prefixed tags (`H1/H1E/H2S/H2E/D1S/D1E/P1S/P1E/P2S/P2E/P3S/P3E/P4S/P4E/P5S`) instead of the long-form tags (`SITENAMESTART/SITENAMEEND/...`).

**Strategy:** add a preprocessing translator that runs BEFORE the existing tag-based parser. The translator detects the short-tag variant, de-interleaves column-split end markers, substitutes short tags for their canonical long-tag equivalents, and strips the new pricing-only markers (P4S/P5S). The existing 3,300-LOC parser pipeline is then invoked unchanged.

**Why this shape:** the existing pipeline (parseTagBased, parseTaggedSections, extractTaggedSiteName etc — ~1,600 LOC of carefully-tuned regex and edge-case handling) already does the hard work for the long-tag variant. Reproducing all that logic for short tags would double the maintenance surface and almost certainly drift. A single deterministic preprocessing pass costs ~80 LOC and guarantees feature parity by construction.

**Purpose:** engineers currently can only upload the unpriced OPS template (long tags). The priced ram template (short tags) produces garbage extraction — site_name comes out as "H1 Cicor Hartlepool Ltd - Training Room H1E H4S Jamie Powis H4E" and equipment rows misattribute to "Hardware" / "Services" / line-item-as-room — because none of the short tags are recognised and they leak into every field. This blocks engineers from importing priced quotes (currently the only project on the system with one is Cicor Hartlepool, project 78).

**Output:**
- 1 modified service (`app/Services/QuoteParserService.php` — ~80 LOC added, 0 LOC modified outside the new methods + the 2-line wire-in at L148).
- 1 new test class (`tests/Unit/Rams/QuoteParserShortTagVariantTest.php` — ~150 LOC, fixture-driven).
- 1 modified test class (`tests/Unit/Rams/QuoteParserServiceTest.php` — +1 snapshot regression test against an unpriced baseline fixture, ~40 LOC added).
- 2 new fixture files (priced Cicor + unpriced baseline, both literal `pdftotext` extractions checked in as `.txt`).
- 0 controller / route / migration / config / schema changes.
- Post-deploy recipe in SUMMARY.md for re-extracting project 78.
</objective>
