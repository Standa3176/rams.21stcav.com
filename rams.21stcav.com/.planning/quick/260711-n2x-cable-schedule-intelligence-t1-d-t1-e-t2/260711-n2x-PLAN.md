<objective>
Layer four upgrades onto the deterministic cable schedule generator so it stops
being a flat inference engine and becomes a signal-aware, survey-aware,
port-aware DAG walker — while keeping every existing test green.

ignores the engineer's cable-route narrative (T1-E loss), leaves the four
port FK columns null even when both stencils have ports (T2-A loss), and
emits one row per source device regardless of how many downstream endpoints
exist (T2-B loss). This bundle closes all four gaps in one plan, one atomic
commit per task, in dependency order.

Output: one modified generator service, one new resolver service (with two
existing consumers refactored to use it), extended unit tests, and no schema
changes.
