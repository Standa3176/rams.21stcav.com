# Quick Task 260503-w77 — Printable PDF Survey Fallback Updated

## Goal

Engineers working offline at sites with no signal download the printable
survey form via `/survey/{token}/download-form`, fill it on paper, then
transcribe back into the digital wizard. The PDF fallback was missing all
17 engineer-feedback fields shipped in 260503-rgg / -tfb / -u2x — paper
capture would silently drop the new data on its way back to the digital
form.

## What changed

### `_header-meta.blade.php` — Site Logistics section added
- Comms room access (☐ Permission required ☐ Outsourced ☐ Free + notes; pre-fills from `$survey->comms_room_access_status`)
- Distance from base (miles + travel notes)
- Site access notes (loading bay / lift / security pass)
- Delivery routes
- Existing parking line now also pre-fills from `$survey->parking_restraints`

### `_blank-room-body.blade.php` — 7 new sub-sections per room
Order matches the digital wizard for clean paper → digital transcription:
1. **Mounting Heights** — screen / camera / booking panel / speaker + 3 "Other" rows
2. **Working at Height — Methods Required** — multi-select checkboxes
3. **Cable Routes Planned** — 4-row table (category / from / to / length / notes)
4. **Wall Construction & Prep** — multi-select + 3 yes/no prep flags + notes
5. **Table Info** — grommets yes/no + count + size + notes
6. **Floor Box Info** — yes/no + power + data outlets + cable space
7. **Brackets Required** — 4-row table (equipment / model / pull-out / notes)

### `_styles.blade.php` — typography tightened
- Table font 8.5pt → 8pt; padding 4pt/6pt → 3pt/5pt
- New h3 styling: teal eyebrow heading with bottom-rule to demarcate sub-sections
- Keeps each room body to ~2 A4 pages including sketch box

## Constraints honoured
- Pure presentation — no controller, service, model, or PDF rendering pipeline changes
- SurveyPdfService::buildFieldFormContents already calls these partials (no wiring change)
- 3 files modified, no files added
- Defensive null handling — pre-fills when survey set, blank-line slots when null
