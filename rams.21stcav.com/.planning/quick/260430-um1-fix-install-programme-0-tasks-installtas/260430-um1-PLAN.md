<objective>
Fix install programme generating zero tasks for every QuoteWerks-imported project.

**Root cause:** `InstallTaskGeneratorService::generate()` reads `$room['equipment']`, but `ProjectDataService::resolveRooms()` returns rooms as bare names with `equipment => []`. The actual equipment lives at `$data['equipment']` (filtered) and `$data['_raw_equipment']` (raw, with `area`/`location` tags). `WorksheetGeneratorService::resolveAndDistributeRooms()` already solves this — port the same two-strategy distribution into `InstallTaskGeneratorService`.

**Purpose:** Restore InstallTask generation for all 3 local projects and the live Integra Building project (21CQ30246-06-OPS). Phase 12 (v1.2) shipped with this latent bug; it likely worked during development against a project where survey data fully enriched rooms.

**Output:**
- `app/Services/InstallTaskGeneratorService.php` updated with private `resolveAndDistributeRooms()` + `buildRoomsFromAreaTags()` helpers (duplicated from WorksheetGeneratorService — kept private to InstallTaskGeneratorService per CLAUDE.md "deferred shared trait" pattern).
- `tests/Unit/InstallTaskGeneratorServiceTest.php` extended with regression coverage for both distribution strategies.
- Live verification deferred to user — they'll regenerate the programme on the Integra project after upload.
</objective>

```php
<?php
// php artisan tinker --execute="require 'storage/app/private/tmp/verify-install-tasks.php';"

use App\Models\Project;
use App\Services\InstallProgrammeService;
use App\Models\User;

$user = User::first();
if (! $user) { echo "ERR: no users\n"; return; }

foreach ([1, 2, 3] as $pid) {
    $project = Project::find($pid);
    if (! $project) { echo "Project {$pid}: NOT FOUND\n"; continue; }

    /** @var InstallProgrammeService $svc */
    $svc = app(InstallProgrammeService::class);
    $programme = $svc->createForProject($project, $user);

    $taskCount = $programme->tasks()->count();
    $roomBreakdown = $programme->tasks()
        ->selectRaw('room_name, count(*) as c')
        ->groupBy('room_name')
        ->get()
        ->map(fn($r) => "{$r->room_name}({$r->c})")
        ->implode(', ');

    echo sprintf(
        "Project %d (%s): %d tasks across rooms — %s\n",
        $pid,
        $project->name ?? 'unnamed',
        $taskCount,
        $roomBreakdown ?: '(no tasks)'
    );
}
```
