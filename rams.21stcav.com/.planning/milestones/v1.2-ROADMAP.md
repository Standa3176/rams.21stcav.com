## Overview

*"From commissioned install plan to signed-off handover"*

Transform the platform from document generator into a live installation delivery system. A reviewed project becomes an auto-generated install programme of room-by-room equipment tasks. Tasks are assigned to engineers with planned dates and a conditional Gantt timeline. Engineers work tasks on a thumb-friendly mobile field view with per-task photo evidence (HEIC-converted server-side), notes, and a clock-in chip. Time entries roll up into an actual-hours dashboard widget. The closing act: a per-equipment commissioning checklist with AVIXA categories, photo evidence per item, client digital signature on a DPI-correct canvas, generated snagging PDF, and project state advance to commissioning.

## Milestone Summary

**Key Decisions:**

- **Canonical task generation reads only from `ProjectDataService::resolve()`** — `InstallTaskGeneratorService` never touches `extracted_data` or `reviewed_data` directly; preserves the v1.0 4-tier merge as single source of truth across all install code paths. ✓ Good
- **Per-item AJAX saves for commissioning, not single-form POST** — engineers work in plant rooms / basements with spotty signal; per-item resilience prevents losing a 30-minute checklist to a single failed POST. ✓ Good
- **`devicePixelRatio` canvas scaling for client signature** — defended against documented signature_pad iOS Retina DPI corruption (GitHub issues #71/#153/#200/#362); human-verified on real iPhone. ✓ Good
- **Read-only Gantt in v1.2** — drag-to-reschedule explicitly out of scope; conditional Gantt threshold at `planned_end - planned_start > 4 days`; week-view table sufficient for the typical sub-week install. ✓ Good
- **Actuals-only time tracking; budget vs actual deferred** — labour budget source (QuoteWerks labour lines vs manual entry) not yet decided. Track actuals now; add comparison when source is settled. — Pending decision
- **Online-only field view (no PWA / service worker)** — AV install sites (offices, venues, data centres) consistently have WiFi; offline complexity not justified. ✓ Good
- **HEIC server-side conversion mandatory** — HEIC client-side support is a silent failure (upload succeeds; GD render fails later). `HeicImageConverter::writeAsJpeg()` is the single seam. ✓ Good
- **Phase 14 ships INST-04g (one-open-entry clock-in guard) early** — Phase 14's mobile field view needs a working clock chip to fulfil its SC; Phase 15 extends with category, heartbeat, and stale-close. Documented in 14-CONTEXT.md "Claude's Discretion." ✓ Good
- **`DocumentArtifactStorage::TYPE_SNAGGING` is intentionally excluded from `LEGACY_ROOTS`** — Phase 16 is a new artifact type with no pre-H-07 history; never read from a legacy path. ✓ Good

**Issues Resolved:**

- INST-01c quantity column gap (added in Phase 12 re-verification cycle)
- INST-02e/f Gantt + slide-over wiring gap (closed in Plan 13-03 after 13-02 left the Gantt scaffold incomplete)
- HEIC silent-failure class (Phase 14 D-11 fail-loud + `HeicImageConverter` writes JPEG with explicit imagick check)
- Alpine `fieldRoot()` + `applyCounters()` factory pattern established for Phase 14, reused by Phase 16's `commissioningRoot()`

**Issues Deferred:**

- **Budget vs actual hours comparison** — labour source decision required (QuoteWerks labour lines vs manual entry); INST-04i marks v1.2 as actuals-only
- **Drag-to-reschedule on Gantt** — read-only timeline only in v1.2; defer to a future quick task if user demand surfaces
- **Push notifications to engineers** — falls under v1.1 NOTF scope (deferred milestone)
- **Phase 12, 13, 15 VALIDATION.md `wave_0_complete: true`** — Nyquist contracts not closed; tracked for post-hoc `/gsd-validate-phase` runs

**Technical Debt Incurred:**

- **REVIEW WR-01 (Phase 15)**: TOCTOU race in `TimeEntryService::closeStaleSessions` — candidate scan does not re-verify staleness inside the row lock; safety net still works, worst case is a false-positive closure with duration ≈ 0
- **REVIEW WR-02 (Phase 15)**: `TimeEntryEditException` message handling inconsistency between heartbeat path (returns generic message) and update path (returns `$e->getMessage()` verbatim); contract hygiene only
- **REVIEW IN-01..IN-06 (Phase 15)**: 6 cosmetic items — dead `clock.error` state, duplicated category list, notes trim asymmetry, redundant ternary, unused eager-load, defensive fallback
- **Outstanding human UAT (Phase 13)**: Gantt rendering, slide-over click, role-based filter — frappe-gantt is built and bundled but browser-based confirmation pending
- **Outstanding human UAT (Phase 14)**: iOS HEIC end-to-end upload — blocked on deploying to a web-accessible environment (LAN tunnel or staging); imagick happy-path test skipped on dev box
