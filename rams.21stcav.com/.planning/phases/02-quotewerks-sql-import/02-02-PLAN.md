## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| QuoteWerksRepository → SQL Server | Outbound parameterised queries only; no write operations |
| QuoteWerksImportService → QuoteImportService | Internal trusted boundary; user object already authenticated |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-02-01 | Injection | QuoteWerksRepository::findByReference() | mitigate | $reference passed via parameterised query (`->where('[DocNo]', $reference)`) — not string concatenation. Laravel query builder handles binding. |
| T-02-02-02 | Injection | QuoteWerksRepository::searchByClient() | mitigate | $clientName passed via parameterised LIKE binding — not `"LIKE '%{$clientName}%'"` string interpolation in raw SQL. Use `->where('[SoldToCompanyName]', 'like', "%{$clientName}%")`. |
| T-02-02-03 | Information Disclosure | QuoteWerksImportService | mitigate | Raw SQL errors from SQL Server contain server internals. Catch \Throwable in the service, log full error server-side, rethrow a generic RuntimeException to the caller. Credentials never appear in logs (Laravel masks PDO DSN). |
| T-02-02-04 | Tampering | QuoteWerksRepository (read-only) | accept | Connection is read-only at SQL Server level. Laravel query builder has no DELETE/UPDATE/INSERT called. Eloquent models forbidden on this connection. |
| T-02-02-05 | Information Disclosure | Charset conversion str() | accept | mb_convert_encoding operates on the string value only; no schema or credential data flows through str(). |
</threat_model>
