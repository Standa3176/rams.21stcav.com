<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| document filesystem → mail attachment | The DOCX/XLSX file is read from `storage/app/documents/...` and sent as an email attachment; wrong path → wrong project's document leaked |
| Blade template render → outgoing email | Project metadata (ref, name) flows from DB into the rendered email body |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-02 | I (Information disclosure) | `*ReadyMail::attachments()` | mitigate | All four mailables route through `DocumentArtifactStorage::readPath(TYPE_X, basename($filename))` — `basename()` strips any directory traversal in the model's `filename` field; `readPath()` is scoped to the typed subdirectory and returns null for paths outside the allowed tree (per H-07 convention in `app/Services/DocumentArtifactStorage.php`). |
| T-09-01 | T (Tampering) | Blade templates | mitigate | All variables rendered with default `{{ }}` Blade syntax = HTML-escaped by Laravel; no `{!! !!}` raw output. project_ref / project_name are validated on intake (Phase 02 quote import) so injection is bounded. |
| T-09-02 | I (Information disclosure) | Cable schedule MIME selection | mitigate | Conditional MIME based on `.csv` vs `.xlsx` extension is computed from `$schedule->source_filename` (DB field, not user input). Worst case = wrong MIME label; never wrong file path because `readPath()` already scoped the lookup to TYPE_CABLE. |
| T-09-05 | D (Denial of service / cost runaway) | Mailable `__construct` serialization | mitigate | All four mailables take a single Eloquent model — `SerializesModels` trait stores only the id (per Pitfall 6). No `->load()` of large collections at construct time; templates re-read fields lazily during render. |
</threat_model>
