<objective>
Extend RULE-02's corrected bands to worksheet output (D-04) and to the
method-statement AI-fallback string, so an engineer reading the worksheet and an
engineer reading the RAMS are never told two different team sizes for the same
display. Fix the specific defect D-04 names: `SafetyProfileService`'s hardcoded
`LARGE_DISPLAY_INCHES = 55` constant AND its keyword-fallback regex, which only
matches a fixed list of common panel sizes (`55|65|70|75|85|86|98|100`) — deleting
the constant alone would NOT make a 43" display fire a warning, because the regex
itself never looks for an arbitrary inch number.

Purpose: D-04 is an explicit, locked decision (not discretion) — "two engineers
reading two 21CAV documents about the same job must not be told different team
sizes." This is Claude's Discretion Open Question 1 resolved: mirror the ≤14"
small-panel exclusion for consistency (a scheduling/control panel still produces no
warning), but do NOT otherwise exempt any resolved display size from producing a
band-appropriate warning.

Output: `SafetyProfileService::roomContainsLargeDisplay()` replaced by a resolver
reading the same general inch-parsing pattern and the same `DisplayLiftPolicy`
bands as the RAMS path; `MethodStatementService::fallbackPhases()`'s Installation
Works step string updated; both existing test files extended to prove parity.
</objective>
