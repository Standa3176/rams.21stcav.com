<objective>
Close GATE-09's last two production bypass paths, both found by Plan 27-06 and recorded in
`.planning/phases/27-manual-handling-display-lift-house-rules/deferred-items.md`.

**Path 1 — the Save Review button.** `RamsController::updateAndDownload()` builds
`$reviewedData['material_handling']` at `:494-502`, mirrors `site_emergency` onto
`$generatedData` at `:584` with a comment explaining exactly why, then calls
`RamsComplianceUpgradeService::upgrade($generatedData)` at `:586`. It never mirrors
`material_handling`. So on the precise request where an engineer has just typed a
non-conforming team size into the form, `enforceDisplayLiftGate()`'s engineer-row loop sees
an empty array. This is the path engineers actually use — leaving it uncovered would make
the gate's live verification overstate what it protects.

**Path 2 — the live PDF reads around the gate.** `resources/views/pdf/rams.blade.php:418`
reads `$rams->reviewed_data['material_handling']` directly, never passing through
`upgrade()`. No generation-side mirror can reach it. The user decided on 2026-08-26 to
re-point the template at the gated source rather than add a second enforcement call site —
a second call site is exactly the divergence risk D-03 exists to prevent.

**Deliberate scope boundary — do not blank historical documents.** RAMS documents generated
before this phase have no `generated_data['material_handling']` key. The PDF read must fall
back to `reviewed_data` when the gated key is absent, so already-issued documents keep
rendering their material-handling table. That fallback technically preserves the ungated
read for historical documents; that is accepted and intended. Those documents are already
issued and cannot be retro-fixed (Phase 26 established the same principle: denormalised
storage means reseeding never retro-changes an issued RAMS). New generations always populate
the gated key, so they always take the gated path.

Output: a one-line mirror in `updateAndDownload()`; a source-preference change in the PDF
template; a feature test proving the Save Review request is blocked; a feature test proving
the PDF reads the gated source for new documents and the fallback for historical ones.
</objective>
