<objective>
Implement D-12 (not-required deliverables drop out of health scoring entirely — no red, no amber, no mention) and D-13 ("Not yet decided" goes amber after a grace period). This is the direct fix named in PHASE.md's own root-cause analysis: a hardware-only project is permanently red today because `ProjectHealthService::assess()` has no way to know a deliverable was never required.

D-13's grace period is set to **7 days**, anchored to this exact file's own existing "Stage duration > 7 days" amber threshold (`ProjectHealthService.php:64`) — the only precedent value in this codebase for "how long before an unattended thing becomes worth flagging". No other value has any basis in the source material.

Purpose: retires the false-red state that provoked this entire phase (Volkswagen Blakelands, hardware-only supply job).
Output: `ProjectHealthService::assess()` extended with 2 not-required guards + 1 new amber rule; `DashboardController` eager-loads `deliverables`; new test coverage for every new branch.
</objective>
