<objective>

**⚠ Revision note — this plan's original "8 wiring points" table was wrong.** A plan-checker review (independently verified by the coordinator against live code) found the table incomplete: it enumerated only the primary "generate from project" button per document type and missed every secondary creation path — manual-form creation with an optional project link, quote-upload auto-linked creation, and regenerate-a-new-version creation. public function autoFlipIfNotRequired(Project $project, string $key, User $user): void
No-op (no state change, no audit row) when the deliverable is not currently `not_required`. Never throws. Safe to call unconditionally after every creation. Every call site in this plan wires this DIRECTLY IN THE CONTROLLER (never a shared service file) — every one of the 16 sites has `$project` resolvable in the calling controller method itself (either a route param, an already-resolved local variable, or one extra `Project::find($someId)` call using an id already in scope), so no service file beyond the 9 controllers listed needs to change.
