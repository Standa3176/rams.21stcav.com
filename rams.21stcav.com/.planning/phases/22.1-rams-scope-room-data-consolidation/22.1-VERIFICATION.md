### Gaps Summary

The phase scored 4 of 6 truths verified. Two truths landed PARTIAL because the read-side of the consolidation is complete but the write-side still emits dead `summary` and `description` keys in 4 canonical writers:

1. **Review form round-trip** (review.blade.php + parseReviewPayload) — the `description` textarea is alive, parseReviewPayload writes both `summary` and `description` keys back into the persisted payload, and editPayload puts them into the blade context. Every save through the review form re-introduces the legacy shape.
2. **Survey-room expansion** (generateSurveyRooms) — when the PM expands `Small Room` → 9 copies, each new room ships with the legacy 6-key shape.
3. **ExtractQuoteJob room scaffold** — new quote imports build 6-key entries from day one. After the production backfill runs, the next quote import re-introduces the keys.
4. **RoomOverviewSummaryService** — the AI summary service writes to the legacy `summary` slot, not the canonical `works_summary`. Callers store the result verbatim, so the canonical key stays empty.

These were flagged by the Phase 22.1 code review (1 Warning / 4 Info — WR-01 + IN-01..04). The threat they pose to the DATA-01/DATA-02 invariants is real: the migration is not self-stabilising. The structural-diff guard test does not catch this because it only exercises the READ path through the normaliser; the normaliser hides the bloat on read but the bloat is still persisted on every write.

DATA-03, DATA-04, DATA-05 are unaffected and fully satisfied. The CLAUDE.md AI-only-for-formatting constraint is honoured. The dead-path classes are deleted and CI-guarded. The backfill artisan is correct, idempotent, and tested. The byte-equivalence canary is green across all 5 waves.

A focused closure plan should target the 8 write-site changes listed in `gaps[].missing` and add a write-side guard test to the structural-diff suite. None of the changes touch render output, so the RamsRenderRegression canary should stay green.
