## Skip-guard pattern used

Two gates, both following the Phase 22 precedent (`CableScheduleXlsxRegressionTest`):

1. **`class_exists(\Spatie\Browsershot\Browsershot::class)`** — cheapest probe; if Browsershot isn't installed there's no point spinning up the Laravel container further.
2. **`is_file($chromePath) || is_executable($chromePath)`** when `env('CHROME_PATH')` is set — defends against CI configs that set CHROME_PATH but haven't yet installed the binary. Bundled puppeteer Chromium (no CHROME_PATH) is NOT probed because puppeteer's auto-resolve cache is opaque from PHP — we accept the rare case where Browsershot itself raises a "Chromium not found" runtime error and treat it as a real failure (not a skip).

Each skip emits a one-liner containing either `"not installed"` or `"not present"` so CI log scrapers can distinguish "binary absent" from "regression failure".
