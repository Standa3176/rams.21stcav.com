- **Found during:** Task 1 grep ratchet
- **Issue:** Four files contained docblock example comments referencing the deleted classes (`BasePrompt.php` `new RamsPrompt(...)`, `AIManager.php` `AIManager::run(new RamsPrompt(), ...)`, `HazardLibraryService.php` 3 mentions, `QuoteExtractorService.php` 1 mention). **3. [Rule 3 — Blocking] Renamed SurveyController output key `works_bullets` → `planned_actions`**

But on inspection, SurveyController was ALREADY reading from `room_overviews[*].works_summary` (line 367) — the only reference to the string `works_bullets` was as the OUTPUT array key name (line 483) feeding the Alpine wizard data structure. Updated 9 corresponding Alpine bindings in `resources/views/surveys/show.blade.php` via `replace_all`. Underlying data source unchanged. Visual contract preserved.
