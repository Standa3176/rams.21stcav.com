Modify `RoomOverviewSummaryService::summarize()` as follows (per D-12):

The method currently builds a `$summaries` map keyed by room name and then merges `summary` back into each room entry. Extend this to also capture and merge `description`.

1. In the `foreach (($decoded['summaries'] ?? []) as $item)` loop (where summaries are indexed by room name), change the map structure from:
   ```php
   $summaries[$room] = $summary;
   ```
   to store both fields:
   ```php
   $summaries[$room] = [
       'summary'     => $summary,
       'description' => trim((string) ($item['description'] ?? '')),
   ];
   ```
   Note: the existing guard `if ($room !== '' && $summary !== '')` should be relaxed to `if ($room !== '')` so that rooms with an empty summary still get their description stored. Update accordingly.

2. In the `array_map` that merges summaries back into room entries, extend the logic:
   ```php
   return array_map(function ($r) use ($summaries) {
       $room     = (string) ($r['room'] ?? '');
       $overview = (string) ($r['overview'] ?? '');
       if ($room !== '' && isset($summaries[$room])) {
           $r['summary']     = $summaries[$room]['summary'] !== ''
               ? $summaries[$room]['summary']
               : $this->fallbackSummary($overview);
           $r['description'] = $summaries[$room]['description'];
       } else {
           $r['summary']     = $this->fallbackSummary($overview);
           $r['description'] = '';
       }
       return $r;
   }, $roomOverviews);
   ```

3. In the fallback path (the final `array_map` after the `catch` block), also set `description`:
   ```php
   return array_map(function ($r) {
       $r['summary']     = $this->fallbackSummary((string) ($r['overview'] ?? ''));
       $r['description'] = '';
       return $r;
   }, $roomOverviews);
   ```

4. Also extend the early-return path (when `$roomsForAi` is empty — rooms have no overview text) to also set `description`:
   ```php
   return array_map(function ($r) {
       $r['summary']     = '';
       $r['description'] = '';
       return $r;
   }, $roomOverviews);
   ```

The existing filter `fn ($r) => is_array($r) && trim((string) ($r['room'] ?? '')) !== ''` is preserved unchanged.
