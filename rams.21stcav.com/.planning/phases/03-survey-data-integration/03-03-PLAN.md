<objective>
Add one-survey-per-project enforcement: SurveyService detects existing surveys and supersedes them atomically, SiteSurveyController surfaces a confirmation block to engineers, the internal create view renders the supersede UI, and unit tests verify the enforcement.

Purpose: Without this plan, engineers can create multiple parallel surveys for the same project. Plan 02's whereNull('superseded_at') filter in ProjectDataService would then silently pick whichever survey is "latest" — the enforcement here ensures only one survey is ever active per project.

Output: SurveyService with supersede logic, controller with detection+confirmation flow, Blade view with .alert-warning supersede block, and SurveyServiceTest with two passing enforcement tests.
</objective>
