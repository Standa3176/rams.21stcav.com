**The actor stamp convention** (same file, both room endpoints):

    'ip:' . ($request->ip() ?: 'unknown') . '|actor:' . substr(hash('sha256', $token), 0, 12)

Audit M-06 replaced `substr($token, 0, 8)` with this because 32 bits of a URL-bearing auth secret
were being persisted. **The stamp is stored and NEVER rendered.**

**Rate limiters** (`app/Providers/AppServiceProvider.php` :200-252) — every public worksheet limiter
is keyed per-token with a load-bearing IP fallback:

    RateLimiter::for('worksheet-photo-write',
        fn (Request $r) => Limit::perMinute(30)->by((string) $r->route('token') ?: $r->ip()));

Existing keys: worksheet-sign (30), worksheet-photo-write (30), worksheet-label-photo-upload (15,
token-only, AI cost), worksheet-status-write (60), worksheet-survey-photo-read (120).

**`room_name` travels in the BODY, not the URL path**, for photo routes — `routes/web.php` explains
why: room names containing `/`, `?`, `#` 404 against the web server's encoded-slash rejection. The
room-complete/survey-reviewed routes DO put it in the path and are the older pattern.
