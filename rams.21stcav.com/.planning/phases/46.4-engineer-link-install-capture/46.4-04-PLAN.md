<objective>
Make the capture surface **read-only the moment a client signs** (D-07). The user:
*"client cannot chage anything as they are signing to confirm work is complete."*

Purpose: there is no login and no second URL (D-01), so the app **cannot tell an engineer from a
client by identity — it tells them apart by STATE.** The engineer captures, hands the device over,
the client signs, and from that instant the record is what was attested to. **The token is the only
credential, so a hidden button is not a permission**: the refusal has to live on the server.

This is a plan of its own, ahead of the kit endpoints, for two reasons. It applies to **five
endpoints that already exist and ship today**, so it can land green before any kit code exists. And
it produces the one guard that plan 05's three new endpoints then inherit, instead of each
reinventing it.

Output: one lock definition, five guarded endpoints, a read-only page that explains itself, and a
controller docblock that no longer contradicts the code.

**NEW PLAN, 2026-09-26, from D-07.** The previous 04 (kit endpoints + drawer) is now 05; the queue
is 06; the walk is 07.
</objective>
