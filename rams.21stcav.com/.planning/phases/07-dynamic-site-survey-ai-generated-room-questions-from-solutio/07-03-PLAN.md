| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-07-03-01 | Tampering | AI JSON shape | mitigate | is_array validation in handle() before persisting; invalid shape → zero records (no partial state) |
| T-07-03-02 | Tampering | question text stored in DB | mitigate | Blade auto-escaping (`{{ $question->question }}`) in all views; never use `{!! !!}` for AI-generated text |
| T-07-03-03 | Spoofing | Job dispatch inside DB transaction | accept | Laravel database queue driver defers dispatch until after transaction commits; documented in RESEARCH.md; acceptable per A1 assumption |
