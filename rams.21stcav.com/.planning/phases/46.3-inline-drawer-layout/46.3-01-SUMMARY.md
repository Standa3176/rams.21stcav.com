## Task 2 — the stretched-link assertion, and the red that proves it bites

`.cav-module` is `position: relative`; `.cav-module__open::after` is `inset: 0`. Giving the anchor
its own `position` collapses the whole-row click target onto the 28px chevron **with nothing else
failing**. cockpit.css warns about exactly that in prose at four places — the shape of a rule that
has never been executable.

Added:

1. **No rule whose selector ENDS in `.cav-module__open` may declare a `position`.** Scanned as
   parsed rules (comments stripped first, because four comment blocks warn in prose about the exact
   declaration being hunted), so `::after` and `:focus-visible::after` — which are supposed to be
   positioned — are excluded by construction rather than by a blacklist.
2. **No rule ending in `.cav-module` / `.cav-module--active` may declare a `position` other than
   `relative`.** "Between" the row and the anchor there is nothing today, which the DOM sibling
   asserts; the docblock says that a wrapper introduced later means **extending** this pair, and
   that deleting it is the failure it exists to catch.
3. **DOM sibling** `test_each_module_row_holds_exactly_one_anchor_and_no_other_interactive_element()`
   — exactly one `<a>` per row, a **direct child** of the row, whose href carries that row's own
   `module=` key, with no `<button>` and no `tabindex`.

Non-vacuity is an **exact membership** (`assertContains('.cav-cockpit .cav-module__open', …)`),
not an `assertGreaterThanOrEqual`, so the house rule on exact counts is not bent.

**THE RED, QUOTED VERBATIM** — produced by injecting `position: absolute;` as the first declaration
of `.cav-cockpit .cav-module__open`:

## Task 3 — D-04

**The early return went in `CockpitModulePresenter::visitPhrase()`**, immediately after the visit
collection is resolved and **before the phrase is built**:

```php
if ($visits->isEmpty()) {
    return '';
}
```

**The reason written at it** (the full comment is ~20 lines above that `if`): that the user said
"strip 0 visits" and were right that `0 visits` is noise; that the same slot renders
`1 visit · reconstructed` and `2 visits · 1 superseded` and — per the method's own docblock — is the
page's ONLY disclosure, with the panel closed, that a visit was **inferred** rather than recorded or
has been **superseded**; that Phase 45's D-02 put it there so a PM would not read an inference as
fact, and there are **24 backfilled visits on live**; that a **full strip was considered and
refused**, three options were put to the user and they chose **hide-at-zero on 2026-09-26**; and
that the suppression is **one mechanism in the place that already owns the decision** — the empty
string is hidden by `module-row.blade.php:62`'s existing `@if (filled($module['count']))`, so **no
second suppression was added in Blade** and none should be.

**`MODULE_MAP` is untouched.** The diff on the presenter is **34 insertions, 0 deletions**, and the
only line in it mentioning `MODULE_MAP` is the comment saying it stays that way. `site_survey` and
`worksheet` are still `COUNT_VISITS`; no count mode, relation or `visit_types` entry moved.

**`0 documents` still renders on RAMS and O&M, deliberately.** The ruling names the visit phrase and
a planner does not widen a user's decision. Recorded at the code, as **CR-2** in the ledger, and
carried to Plan 46.3-04's human checkpoint as an open question. Two assertions in
`CockpitSpineTest` now guard the scoping, so an agent who strips it without asking goes red.

### The retired assertion and its successor

**Retired by name, citing D-04 (revised 2026-09-26):** the line at `CockpitSpineTest:658` inside
`test_an_empty_project_still_renders_every_module_row_waiting()` —

```php
$this->assertSame(count($modules), $this->countByClass($html, 'cav-module__count'));
```

— "every module row renders exactly one count element". It cannot hold: on an empty project the two
`COUNT_VISITS` rows render none. It was **not deleted**; the old line, its own 46.2-01 history and
the reason are all written in place above the successor, and it is logged as **A-1** in the ledger.

**Successor**, `CockpitSpineTest::test_a_row_renders_a_count_if_and_only_if_that_count_is_non_empty()`,
asserting **both directions** over four fixtures (nothing / visits only / documents only / both),
driven off `CockpitModulePresenter`'s own output and never a literal:

```php
foreach ($this->presentedCounts($project) as $title => $count) {
    if ($count === '') {
        $seen['empty']++;
        $this->assertSame('', $this->rowCount($html, $title), /* D-04: a row with nothing to say says nothing */);
        continue;
    }
    $seen['rendered']++;
    $this->assertSame($count, $this->rowCount($html, $title), /* verbatim, suffixes included */);
}
// NON-VACUITY, BOTH WAYS.
$this->assertNotSame(0, $seen['empty'], 'No suppressed count was exercised.');
$this->assertNotSame(0, $seen['rendered'], 'No rendered count was exercised.');
```

The forward half ("empty means absent") is what D-04 asked for. **The reverse half ("non-empty means
present, and byte-identical") is the point**: a one-directional version would go on passing while
`1 visit · reconstructed` silently stopped rendering, which is the exact regression hide-at-zero
exists to avoid. It is stronger than what it replaced, which could not have noticed a vanished
phrase so long as the total still added up.

### The disclosure-survives test
