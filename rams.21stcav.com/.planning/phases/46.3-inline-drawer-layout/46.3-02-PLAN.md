<objective>
Move the panel from a right-hand column to an inline drawer directly beneath the row that was
clicked (D-01), collapse the other rows away while it is open (D-02), and give the user an obvious
way back — because with the other rows gone, the close control is the ONLY route to the module list
and a small `×` would be a trap.

Then re-take the read-only fence against the page this restructure produces: judge BOTH
`cockpitRegion()` brackets deliberately, re-run the three-way breakage ritual, and close the NEW
vacuity risk that collapse-away introduces — an open-module region now holds one row where it used
to hold four, so any assertion that iterates rows can go quiet without going red.

Purpose: DL-01, DL-02 and the fence half of DL-06 — this is the phase's structural change and the
riskiest plan in it. Output: a one-thing-at-a-time cockpit whose fence has been proven capable of
failing on this commit.

**THIS PLAN DOES NOT REOPEN WHAT THE PANEL CONTAINS.** The tabs, the progress ring, the visit list,
the document form and its field map are 46.2's and are not in scope. If this plan finds itself
editing `CockpitDocumentFormPresenter` or `doc-form.blade.php`'s fields, it has drifted — stop and
report. The panel's markup is touched ONLY for the way-back control and for whatever class names
the new position requires.
</objective>
