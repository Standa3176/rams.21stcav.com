<objective>
Hide the module row's visit phrase when the count is zero and keep it, unchanged, when it is not
(D-04, REVISED). Relabel the closed-state generate control so the Word/PDF choice behind it is
discoverable (D-05). And — before any layout work starts — strengthen the stretched-link assertion
so the silent failure mode this phase is most likely to ship is caught by a test rather than by
review.

Purpose: these three changes touch the ROW and the ROW'S ONE CONTROL. They are independent of the
drawer's position, so they land first, green, and every later plan inherits a click-target assertion
that already bites.

Output: rows that say nothing when there is nothing to say and say exactly what they say today when
there is; a generate control that reads as opening a form and names the formats it will offer; a
widened click-target test; and `46.3-COUNT-LEDGER.md`, where every count and every retired assertion
in this phase is recorded by name.

**⚠ D-04 WAS REVISED ON 2026-09-26 AND THE EARLIER READING IS WITHDRAWN.** An earlier draft of this
plan proposed moving `site_survey` and `worksheet` from `COUNT_VISITS` to `COUNT_DOCUMENTS`. **That
is withdrawn.** Planning surfaced what a full strip would cost — the same slot renders
`1 visit · reconstructed` and `2 visits · 1 superseded`, which `visitPhrase()`'s own docblock calls
*the page's at-rest disclosure slot*, the only place a backfilled or superseded visit is disclosed
without opening anything, and there are **24 backfilled visits on live**. The user was reacting to
`0 visits` on an empty project, not asking to lose that warning. Presented with three options they
chose **hide-at-zero**.

So: **do NOT touch `MODULE_MAP`'s count modes. Do NOT touch its relations. Do NOT add a
cross-presenter relation guard.** `site_survey` and `worksheet` stay on `COUNT_VISITS`.

**THIS PLAN ADDS NO FORMAT, NO ROUTE AND NO FIELD.** D-05 is a relabel. `CockpitDocumentFormPresenter`
is NOT edited, `DOCUMENT_FIELD_MAP` is NOT edited, and `DocumentFormatInventoryTest` must stay green
with its missing set exactly `['worksheet.pdf']`. If this plan finds itself opening the form
presenter, it has drifted — stop and report.
