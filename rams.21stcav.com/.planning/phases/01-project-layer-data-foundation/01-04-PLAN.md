<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| QuoteImportService → ProjectService::transition() | Auto-advance hook — system-initiated, not user-controlled |
| SurveyService → ProjectService::transition() | Auto-advance hook — system-initiated, not user-controlled |
| ProjectDataService output → show.blade.php | Canonical dataset rendered in Blade — must be HTML-escaped |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | Auto-advance hook triggers | accept | Hooks triggered by internal service calls (confirm, survey submit) — not exposed as external endpoints; no external user can directly invoke transition() |
| T-04-02 | Denial of Service | Auto-advance hook exception | mitigate | Both hooks wrap transition() in try/catch \InvalidArgumentException — failure is logged and swallowed; primary action is never blocked |
| T-04-03 | Information Disclosure | Canonical dataset in Project Data tab | accept | Tab is only visible to authenticated users; internal tool; no PII beyond business data; data_source labels are informational only |
| T-04-04 | Injection | canonicalData rendered in Blade | mitigate | All values output via `{{ }}` double-brace (Blade auto-escapes HTML); no `{!! !!}` raw output used in this view |
| T-04-05 | Repudiation | Auto-advance transitions not logged | mitigate | ProjectService::transition() logs to ProjectActivityLog internally — auto-advance transitions carry the same audit trail as manual transitions |
</threat_model>
