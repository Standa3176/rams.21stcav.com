**Change 1 — index(): remove forUser scope from main query (line ~37-39)**
Replace:
```php
$query = Project::with('latestPackage')
    ->forUser(auth()->id())
    ->orderByDesc('updated_at');
```
With:
```php
$query = Project::with('latestPackage')
    ->orderByDesc('updated_at');
```

**Change 2 — index(): remove forUser scope from statusCounts (line ~57)**
Replace:
```php
$statusCounts = Project::forUser(auth()->id())
    ->selectRaw('status, count(*) as total')
    ->groupBy('status')
    ->pluck('total', 'status');
```
With:
```php
$statusCounts = Project::query()
    ->whereNull('deleted_at')
    ->selectRaw('status, count(*) as total')
    ->groupBy('status')
    ->pluck('total', 'status');
```

**Change 3 — index(): add site_address to search orWhere chain (line ~48-52)**
Replace:
```php
$query->where(function ($q) use ($search) {
    $q->where('name', 'like', "%{$search}%")
      ->orWhere('client_name', 'like', "%{$search}%")
      ->orWhere('ref', 'like', "%{$search}%");
});
```
With:
```php
$query->where(function ($q) use ($search) {
    $q->where('name', 'like', "%{$search}%")
      ->orWhere('client_name', 'like', "%{$search}%")
      ->orWhere('site_address', 'like', "%{$search}%")
      ->orWhere('ref', 'like', "%{$search}%");
});
```

**Change 4 — store(): add quote_reference validation rule**
Replace the validation array in store():
```php
$validated = $request->validate([
    'name'              => ['required', 'string', 'max:200'],
    'ref'               => ['nullable', 'string', 'max:50'],
    'client_name'       => ['required', 'string', 'max:150'],
    'site_address'      => ['required', 'string', 'max:500'],
    'works_description' => ['nullable', 'string'],
    'notes'             => ['nullable', 'string'],
]);
```
With:
```php
$validated = $request->validate([
    'name'              => ['required', 'string', 'max:200'],
    'quote_reference'   => ['required', 'string', 'max:50'],
    'client_name'       => ['required', 'string', 'max:150'],
    'site_address'      => ['required', 'string', 'max:500'],
    'works_description' => ['nullable', 'string'],
    'notes'             => ['nullable', 'string'],
]);
```
Note: remove the old 'ref' nullable rule — quote_reference replaces it as the required field. The 'ref' column is the internal auto-ref; quote_reference is the user-provided QuoteWerks reference.

**Change 5 — store(): add similar-project warning before create()**
After the $validated block but before the $project = $this->service->create() call, insert:
```php
// D-14: Warn (but allow) when a project with matching client+site already exists.
$similarExists = Project::whereRaw('LOWER(client_name) = ?', [strtolower($validated['client_name'])])
    ->whereRaw('LOWER(site_address) = ?', [strtolower($validated['site_address'])])
    ->whereNull('deleted_at')
    ->exists();
```
Then update the return to pass the warning when $similarExists:
```php
$project = $this->service->create(auth()->user(), $validated);

$redirect = redirect()->route('projects.show', $project);

if ($similarExists) {
    $redirect = $redirect->with('warning', 'A project with the same client and site address already exists. Please confirm this is a separate project.');
} else {
    $redirect = $redirect->with('success', "Project \"{$project->name}\" created.");
}

return $redirect;
```

**Change 6 — show(): relax ownership check to auth()->check() only (per D-15, D-19)**
Replace lines ~102-105:
```php
// Security: only the project owner (or an admin) may view the project.
abort_if(
    $project->user_id !== auth()->id() && auth()->user()?->role !== 'admin',
    403
);
```
With:
```php
// D-15: Projects are shared across all authenticated users.
abort_unless(auth()->check(), 403);
```

**Change 7 — transition(): replace authorizeProject() with auth check only (per D-19)**
In transition(), replace:
```php
$this->authorizeProject($project);
```
With:
```php
// D-19: Any authenticated user can trigger lifecycle transitions.
abort_unless(auth()->check(), 403);
```

Also add a Log::info call after the successful transition for audit purposes (it already logs inside ProjectService::transition() but the controller log is useful for HTTP layer tracing):
No additional log needed — ProjectService already handles it. Do not duplicate.

Important: Do NOT remove authorizeProject() from edit(), update(), archive(), reopen(), and destroy() — those should remain owner/admin protected because they are destructive or editorial operations. Only show() and transition() are relaxed per D-15/D-19.
