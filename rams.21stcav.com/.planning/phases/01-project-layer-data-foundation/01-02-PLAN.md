<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → ProjectController::index() | `?client=` and `?status=` query params from user |
| ProjectController::show() → Blade | `$linkedRecords` array output rendered in templates |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Injection | `?client=` filter param | mitigate | Passed to Eloquent `where('client_name', $client)` — parameterized binding, no raw SQL interpolation |
| T-02-02 | Information Disclosure | Linked records in show view | accept | All authenticated users have equal access to all project data per D-15; no PII beyond business data |
| T-02-03 | Tampering | Action button routes in $linkedRecords | mitigate | Route names are server-defined; user cannot inject route targets; all resulting routes require authentication |
| T-02-04 | Spoofing | Breadcrumb Project Name output | mitigate | Rendered via `{{ $project->name }}` (Blade auto-escapes, XSS safe) |
| T-02-05 | Denial of Service | Eager loading 5 relationships in show() | accept | limit(5) on each relationship constrains query size; acceptable for internal tool scale |
</threat_model>
