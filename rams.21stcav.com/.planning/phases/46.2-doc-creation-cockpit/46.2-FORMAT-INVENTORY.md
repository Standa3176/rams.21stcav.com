## Why Worksheet -> PDF is a GAP and not an oversight

Three measured facts, each independently sufficient:

1. **`pdf.engineer-report` is a different document.** `worksheets.engineer-report-pdf`
   (`routes/web.php:704`) renders `pdf.engineer-report` from
   `EngineerActivityService::buildReportContext($worksheet)` — the engineer's *activity* report
   (outstanding items, per-room photos, sign-offs) produced after a site visit. It is not the
   worksheet a PM generates up front.
2. **It 404s for exactly the user this phase serves.** `WorksheetController.php:110` —
   `abort_if(! $worksheet->hasEngineerActivity(), 404, 'No engineer activity yet — nothing to
   report.')`. A PM creating a worksheet has no engineer activity, so pointing the Worksheet row's
   PDF control at this route would ship a button that 404s on its normal first use.
3. **There is no worksheet PDF Blade.** `ls resources/views/pdf | grep -i work` returns nothing
   (exit 1 — pasted below). Producing a Worksheet PDF therefore means **authoring a new render
   target**, which D-04 explicitly forbids in this phase ("Do not write new generators… Where a
   format is missing for a document type, say so rather than inventing a second renderer").

Per **D-05**: the panel must say plainly that PDF is unavailable for this document rather than
offering a control that fails.

## The decision the user has not yet taken

DC-07 is recorded **NOT DELIVERED**. Three options with their costs. **None is chosen here.**

- **(a) Accept Word-only for the Worksheet in 46.2.**
  Cost: the Worksheet row becomes the one asymmetric row on the page; a PM who wants a PDF makes one
  from the .docx themselves. Zero new code, zero new render target, D-04 respected as written.
- **(b) Authorise `resources/views/pdf/worksheet.blade.php` as its own phase.**
  Cost: a new render target, therefore outside D-04 and outside this phase. Somebody must first
  decide what a Worksheet PDF *contains* — a content decision before it is a code one — plus a
  Browsershot render path, page-break work, and a new test surface.
- **(c) Offer the engineer-activity report as the Worksheet's PDF.**
  Cost: honest ONLY if it is **relabelled** (e.g. "Engineer activity report"), because it is not the
  worksheet; and it still 404s until an engineer has visited, so the control needs a disabled state
  driven by `hasEngineerActivity()`. Mislabelled, it is a PM downloading a document that is not the
  one they asked for.
