<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| PM browser → `POST projects/{project}/cockpit/documents` | The cockpit's first multi-field write; untrusted strings reach a payload a document generator later renders |
| stored payload → DOCX/PDF renderer | PhpWord and a Blade-to-Chromium pipeline consume values the PM typed |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-46.2-12 | Tampering | `module` in the POST payload | mitigate | `Rule::in(array_keys(documentFieldMap()))` applied BEFORE any lookup; no filesystem path or class name is ever built from it. Asserted with `../../etc/passwd`, matching the existing visit-route proof. |
| T-46.2-13 | Elevation of Privilege | Cross-project write via an id in the payload | mitigate | Every record is reached through the route-bound `{project}` — `$project->latestPackage`, `$project->siteSurveys`, `$project->worksheets`. No id from the request ever selects a row. Asserted with a second project's survey id in the payload. |
| T-46.2-14 | Cross-Site Request Forgery | The new POST | mitigate | `@csrf` on the form and the `web` group's `VerifyCsrfToken`; asserted by a POST without a token. |
| T-46.2-15 | Injection | PM strings rendered into DOCX via PhpWord | mitigate | `WorksheetDocxService` already sets `Settings::setOutputEscapingEnabled(true)`; confirm the same for the site-survey and O&M writers and RECORD the finding if one of them does not — do not change a generator in this phase, raise it. |
| T-46.2-16 | Injection | PM strings rendered into PDF via Blade + Chromium | mitigate | The PDF Blades escape with `{{ }}` / `e()`; the one `{!! nl2br(e(...)) !!}` pattern in `summary.blade.php` escapes before nl2br, which is the safe order. Assert one hostile-string round trip through a generated PDF rather than reasoning about it. |
| T-46.2-17 | Information Disclosure | Error messages reflecting submitted values | mitigate | `{{ $message }}` only, never `{!! !!}` — the T-46-04-07 rule the retired form already carried, restated in the new component's docblock. |
| T-46.2-SC | Tampering | npm/pip/composer installs | accept | This plan installs no package. `phpoffice/phpword`, `spatie/browsershot` and every generator dependency are already direct requirements in use. |
</threat_model>
