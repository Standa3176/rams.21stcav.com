## The rule that was applied, identically, everywhere

Each test class was split along ONE line:

- An assertion that **POSTs to a route and checks the DATABASE or the RESPONSE stays exactly as
  written.** It proves the kept code, and the kept code is unchanged.
- An assertion that **renders the cockpit and checks for MARKUP or COPY is retired** — by name, at
  its former position, with the decision cited and a replacement or a named reason.

**Nothing was deleted to make a red test pass.** Where a count moved (4 → 0, 9 → 4, 18 → 21) the
number stayed EXACT and moved by name with the test it was copied from. Three
`assertLessThanOrEqual`s and one `assertGreaterThanOrEqual` were converted to equalities, because an
inequality is only defensible while the bound is non-zero.
