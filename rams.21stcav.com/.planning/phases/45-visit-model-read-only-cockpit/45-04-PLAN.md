<objective>
The D-06 split, in the only shape that is achievable behaviour-preservingly: a new durable parent
table **above** `install_programmes`, with a **nullable** FK on `install_programmes`.
`install_tasks` do **not** move.

`InstallProgramme::create([...])` — every regenerate produces a brand-new row, so anything filed

does not change.

behaviour-preserving, and that "if the split cannot be made behaviour-preserving, **stop and raise
it** rather than relaxing criterion 4". The gate is the pass count measured in Plan 45-01.

method, one idempotent link command, and a test that proves durability across a regenerate.
