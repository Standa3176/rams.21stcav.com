<why_this_field_and_not_another>

| Typed input on the page today | Who types it | How it persists |
|---|---|---|
| per-tray photo label (~`:1143`) | engineer | rides **with** the photo upload, not a save cycle |
| kit qty / description (~`:1738`, `:1746`) | engineer | its own three fetch endpoints, already offline-queued |

are **buttons, not typed fields.** Autosave does not apply to a button.

this plan adds it. It is **additive capture, not a redesign** — every existing capture field is left
exactly as it is (see `<do_not_drift>`). It is also precisely SCC's `room_states[].observations`, the
field the sibling app's autosave was built for, which is why the shape transfers.

⚠️ **This gap is flagged to the user at plan 04's checkpoint.** If they say the phase should ship
tabs with no new field, the endpoint and the field come out and `DraftStore` stays unwired — say so at
the checkpoint rather than defending it.

⚠️ `EngineerLinkSignoffLockTest::test_every_unlisted_public_controller_method_calls_the_capture_lock`
reflects over every public method **declared on** `PublicWorksheetController`, subtracts a seven-entry
allow-list, and asserts the rest contain the literal `WorksheetCaptureLock::isLocked`. **That is
deliberate and it will fail by name if `saveRoomNotes` is unguarded:**

> These public PublicWorksheetController methods write without the D-07 capture lock and are not on
> the reasoned allow-list: **saveRoomNotes**.

**`saveRoomNotes` must NOT be added to the allow-list.** It is a capture write: the notes are part of
the record the client signs, so they must freeze when the record freezes. The allow-list's two
status-confirmation entries (`markRoomComplete`, `markSurveyReviewed`) are *status*, not the captured
record — a note is the record.

The guard sits on the **first line after `resolveWorksheet()`, before validation** (T-46.4-04-05: a
locked caller must not learn which field was malformed). It returns **422**, not 423 — the page's
hand-rolled fetch handlers have never seen 423, and 422 is this controller's refusal idiom. The body
is `{"message": …}` carrying `WorksheetCaptureLock::MESSAGE` verbatim:

> This worksheet has been signed off — it can no longer be changed.

**That sentence is what plan 01's ruling requires the engineer to read when a held draft is refused,
and the draft must survive being refused.**
