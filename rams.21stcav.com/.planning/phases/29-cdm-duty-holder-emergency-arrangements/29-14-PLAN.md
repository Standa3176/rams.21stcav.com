<interfaces>
`php artisan rams:regenerate-snapshots [fixture?] [--force]` — the one command that regenerates all
four golden files for a fixture in one run (HTML v1/v2 via the PDF blades, DOCX v1/v2 via
`DocxBuilderService`/`DocxBuilderServiceV2`). Without `--force` it prints a diff prompt and requires
interactive confirmation; with `--force` it overwrites immediately. Runs against an in-memory sqlite
DB, never touches the real database (see the command's own class docblock).

Snapshot tests are tagged `@group snapshot` and excluded from the default `php artisan test` run
(`phpunit.xml` `<exclude>snapshot</exclude>`) — must be run explicitly with `--group snapshot`.
</interfaces>
</context>
