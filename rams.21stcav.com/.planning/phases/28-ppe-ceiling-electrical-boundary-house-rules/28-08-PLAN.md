## ⚠️ Deploy order is NOT free choice — follow it exactly

Production measurement (`28-07-MEASUREMENT.md`, 2026-09-06) found **54/54 documents carry FFP2**
and **52/54 carry a hazard named `"Confined Spaces"`**. `config/rams_tier1.php:98` defaults
`ffp2_confined_space_gate_enabled` to **`true`**.

The Save Review path (`RamsController.php:603`) calls `upgrade()` on `generated_data` **directly**,
bypassing both `reviewedToRisk()`'s tier-1 correction and `LegacyHazardNameFoldMap`'s name
resolution. So a deploy that arms the gate before the migration runs **blocks Save Review across
effectively the entire live corpus.** That is an outage, not a gate doing its job.

**Sequence — do not reorder, do not skip step 3:**

1. `git pull` **as `stcav`, never as `root`.** A Phase 27 verification run as root silently failed
   `git pull` on dubious ownership, reported "Nothing to migrate", and tested pre-fix code while
   looking like a failed verification. If `git pull` reports anything unexpected, STOP.
2. Set `RAMS_PPE_CEILING_ELECTRICAL_GATE=false` in `.env`, then `php artisan config:clear`
   (this app runs `config:cache` in production — a bare `.env` edit will NOT take effect without
   clearing, and grepping `.env` will lie to you about the live value; confirm via
   `php artisan tinker --execute="var_dump(config('rams_tier1.ffp2_confined_space_gate_enabled'));"`).
3. `php artisan migrate` — run Plan 28-07's backfill.
4. **Re-run the Pass-1 and Pass-2 scans from `28-07-MEASUREMENT.md`. Require
   `ppe_ffp2 = 0` and `hazard_NAME_confined = 0`.** If either is non-zero, the migration is
   incomplete — STOP and report. Do not arm the gate.
5. Only now remove the `RAMS_PPE_CEILING_ELECTRICAL_GATE` override (or set it `true`), and
   `config:clear` again. Re-confirm the config value as in step 2.
6. Regenerate 21CQ30960 through the **DOCX** path and confirm `status = completed`,
   `error_message = null`, and the textual absence/presence checks.
7. Record which generation path the regeneration exercised (`runPipeline()` or `runFromReview()`).

**Rollback:** `RAMS_PPE_CEILING_ELECTRICAL_GATE=false` + `config:clear` disarms both gates
instantly with no redeploy, and does not touch GATE-09.
