**CRITICAL — red-test-discipline:**
- Each test extends `Tests\TestCase` and uses `RefreshDatabase`.
- Tests reference classes that do not yet exist (e.g., `App\Models\CommissioningItem`). When the class cannot be resolved, the test must still be registered (not a fatal parse-time error). The pattern: write the test using `use App\Models\CommissioningItem;` — PHP will defer resolution until the method runs, and PHPUnit reports the test as "Error" (red) rather than failing to collect. This is the desired state.
- Factories reference model classes that do not yet exist — same deferred-resolution trick applies (factories use `class-string` via `protected $model = \App\Models\CommissioningItem::class;` which is resolved at instantiation).
- NO `$this->markTestSkipped(...)` — tests must run red, not skip.
- NO mocks of classes that don't exist yet — the test failure mode is runtime class-not-found, which counts as red.
