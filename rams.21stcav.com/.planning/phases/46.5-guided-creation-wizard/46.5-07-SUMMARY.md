### Fixes made while writing this file, and why (Rule 1 / Rule 3)

- **Naming collision (Rule 3, blocking).** The first draft's helper method was named `get()`, which
  collides with `Illuminate\Foundation\Testing\TestCase::get()` (the same class of collision
  46.5-01's `groups()` and 46.5-04's `post()` hit before). Renamed to `openStep()`.
- **RAMS fixture was not generation-ready (Rule 1, bug in the test itself).** The first draft's
  `ProjectPackage::extracted_data` fixture was too thin for
  `RamsController::generateFromProject`'s `RamsReviewValidatorService` to pass, so no `RamsDocument`
  was ever created and the test asserted a false negative. Fixed by mirroring the proven
  generation-ready shape from `CockpitDocumentFormTest::reviewedPackage()` (`overview`,
  `method_statement_notes`, `project`, `activities`, `ppe` alongside `room_overviews`/`equipment`).
- **Worksheet photo-tray fixture (Rule 1).** `Bus::fake()` means the AI build never actually runs, so
  a freshly-created worksheet has no rooms to render trays for. Fixed by seeding
  `generated_data.rooms` and `status = STATUS_FINAL` directly, and by creating `WorksheetPhoto` rows
  through the model's own required-field shape (`room_name`, `filename`, `original_name`,
  `mime_type`, `sort_order`) rather than a non-existent factory.
- **Photo-tray count assertion was counting the wrong substring (Rule 1).** `public-show.blade.php`'s
  own inline script repeats the literal selector string `[data-photo-tray]` twice outside the markup,
  which inflated a bare `substr_count($body, 'data-photo-tray')` from 3 to 5. Fixed to count the
  longer, markup-specific substring `class="photo-tray" data-photo-tray`.
- **Supersede fixture chose the wrong branch of `SurveyService::createFromProject` (Rule 1).**
  `createFromProject(..., supersede: true)` DISCARDS an untouched survey outright rather than
  archiving it — a different, equally real code path from the one this state is meant to exercise.
  Fixed by setting `surveyor_name` on the fixture survey first, so it is "touched" and the genuine
  archive-and-recreate branch runs.
