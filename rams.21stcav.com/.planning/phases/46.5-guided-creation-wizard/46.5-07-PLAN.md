<standing_constraints>
CARRIED VERBATIM IN EVERY PLAN OF THIS PHASE.

- **No JavaScript, no Alpine** in the cockpit region. Step state is query-string
  (`?module=…&step=2`), like the panel and tabs. Fence counts **2 / 21 / 9 / 13**, moved only **by
  name with a reason**. `<select` is still banned and a wizard may genuinely need one — **lift it by
  name in the commit that ships it, never by deletion.**
- ⚠️ **The stretched-link trap**: `.cav-module` has `position: relative`, `.cav-module__open::after`
  has `inset: 0`. A `position` **or a `transform`** on the anchor collapses the whole-row click
  target onto the 28px glyph **with nothing failing**. Run `CockpitVisualTest` after every CSS edit.
- ⚠️ **Guard tests match COMMENTS** — pinned counts (` x-data` 1, ` x-show` 1, ` x-model` 2,
  ` x-cloak` 1, `{!!` 1) have nearly been broken six times by prose.
- ⚠️ **Tests run sqlite `:memory:`; live is MySQL.** A migration can pass every gate and be
  impossible on live — the 64-char identifier cap did exactly that on 2026-09-27, and MySQL DDL is
  not transactional so the retry lied with "table already exists". **Name every composite index
  explicitly.**
- The three protected files stay **BYTE-IDENTICAL to `4abd2b24`** (a mismatch is a STOP). `@php`
  inside a Blade `{{-- --}}` comment **still compiles**. **`resources/css/cockpit.css` is a Vite
  entry** — if touched, the deploy note must say `npm run build`.
- **NEVER `artisan migrate:fresh --env=testing`; NEVER `state.advance-plan`/`state.update-progress`;
  NEVER `git stash`.** `gate-46.ps1` **foreground, redirected not piped, one suite per invocation**;
  a killed stall reports exit 0.
- Gates: cockpit **387 / 0** (two runs summed), `tests/Feature/Worksheets`, `tests/Feature/Documents`,
  the three sha256 pins, and the **D-06 baseline `>= 159 passed AND 0 failed` — NEVER equality
  against 161.**
</standing_constraints>
