All colors are the existing CSS custom properties from `:root`. Do not introduce hex values not already in the token set.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--bg)` = `#F3F6F7` | Page background |

Accent (`var(--teal)`) is reserved exclusively for:

Secondary semantic colors (from `dash-status-badge` color map — use only for status indicators):

- Failed: `#DC2626` (`var(--danger)`)

## Surface Patterns: Three Phase 4 UI Surfaces

### Surface 1: Project Show Page — Generate Buttons (modify existing)

**Location:** `resources/views/projects/show.blade.php` — Linked Records card, inside `@foreach($linkedRecords as $entry)`.

**Current state:** Worksheet row shows "Coming in Phase 4." text. O&M and Cable Schedule rows have an `empty_action_label` form button using `.btn-outline btn-sm`.

**Required changes:**

Replace the static "Coming in Phase 4." text and the generic empty-action button pattern with a three-state generate button per document type.

**Three-state button pattern (Alpine.js `x-data`):**

State 1 — No document or status `failed`:
```
[Generate Worksheet]  ← .btn-teal btn-sm, POST form dispatch
```

State 2 — Status is `pending` or `generating`:
```
[⟳ Generating…]  ← .btn-outline btn-sm, disabled, aria-disabled="true"
                      spinner: inline SVG 14px, animate-spin via inline CSS
```

State 3 — Status is `draft` or `final`:
```
[↓ Download]  ← .btn-teal btn-sm, href to download route
[View]         ← .btn-outline btn-sm, href to show route (if show view exists)
```

**Polling mechanism:** Alpine.js `x-init` with `setInterval` polling `GET /worksheets/{id}/status` (JSON: `{ status, download_url }`). Poll every 4 seconds. Stop polling when status is `draft`, `final`, or `failed`. On failed: replace spinner with `.btn-danger-outline btn-sm` "Retry" button that submits the generate form again.

**Layout:** Buttons render inside the existing `@if($entry['records']->isEmpty())` empty block and the existing table `.actions` cell — no structural changes to the card.

**Badge for Worksheet type label:** Use `.badge-teal` (matches Survey badge pattern seen in linked records).

## Interaction Contracts

### Generate Button Flow

1. User clicks "Generate Worksheet" / "Generate O&M Manual" / "Generate Cable Schedule"
2. Form POST dispatches job. Server returns redirect back to project show with `session('success')`.
3. Page reloads showing the generating state (status `pending` or `generating`).
4. Alpine.js `x-init` begins polling `GET /{resource}/{id}/status` every 4 seconds.
5. When status is `draft` or `final`: replace spinner button with "↓ Download" (`.btn-teal`) and "View" (`.btn-outline`). Stop polling.
6. When status is `failed`: replace spinner with `.alert-error` inline + "Retry Generation" (`.btn-danger-outline btn-sm`). Stop polling.

**Polling endpoint response shape:**
```json
{ "status": "generating", "download_url": null }
{ "status": "draft", "download_url": "/worksheets/42/download" }
{ "status": "failed", "error": "AI timeout after 2 attempts" }
```

### Worksheet Room Accordion

- Default state: all rooms collapsed.
- Click room header: expand/collapse that room body. One room can be open at a time (no forced exclusivity — multiple may be open if user prefers; do not enforce accordion exclusivity).
- Chevron rotates 90deg on open via CSS `transition:transform 200ms`.
- Alpine.js: `x-data="{ open: false }"` per room, `@click="open = !open"`, `:class="{ 'open': open }"` on body and chevron.

### Download Link Behaviour

- DOCX download: `<a href="{{ route('worksheets.download', $worksheet) }}" target="_blank">`. No JavaScript required.
- XLSX download (Cable Schedule): same pattern.
- PDF download (O&M Manual): same pattern.

### Form Submission Guards

- Generate buttons: `onclick="return confirm('Generate worksheet for {project.name}? This may take up to 60 seconds.')"` — only if a worksheet already exists (re-generation). No confirmation on first generation.
- Delete worksheet: `onclick="return confirm('Delete this worksheet? The DOCX file will be removed and cannot be recovered.')"` — always required.
- No other destructive actions in Phase 4.
