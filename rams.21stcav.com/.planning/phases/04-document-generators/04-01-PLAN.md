## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Auth user → WorksheetController | Authenticated user triggers generation and download |
| Controller → Queue job | Job receives only a scalar ID — no user-supplied data passes through queue boundary |
| AI provider → WorksheetPrompt | AI response is parsed for JSON only; install_steps is treated as text (no eval, no HTML) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01-01 | Spoofing | WorksheetController::generateFromProject | mitigate | abort_if($project->user_id !== auth()->id() && !isAdmin(), 403) — matches OmManual pattern |
| T-04-01-02 | Elevation | WorksheetController::download | mitigate | abort_if ownership check before serving file; Storage::disk('local') path is not user-controlled |
| T-04-01-03 | Information Disclosure | worksheets.status JSON endpoint | mitigate | Verify ownership before returning status JSON (same abort_if check as download) |
| T-04-01-04 | Tampering | WorksheetGeneratorService AI response | mitigate | AI response parsed as JSON, install_steps extracted as string — never eval'd or rendered as HTML (use {{ }} not {!! !!} in Blade) |
| T-04-01-05 | Denial of Service | BuildWorksheetJob per-room AI calls | accept | Sequential AI calls per room; tries=2 with 300s timeout; large projects may be slow but will eventually complete or fail cleanly |
</threat_model>
