<objective>
D-02/D-03, the half of the comms-room decoupling 46.8-RESEARCH found that CONTEXT's named consumer
list did not include: the site-survey's OWN Word document (`SiteSurveyDocxService`) and PDF header

explicitly overrides that, having been shown the cost. This plan is the override, applied to the
specific files 46.5 named.

link, while the `comms_room_access_status`/`comms_room_access_notes` columns stay on disk, untouched,
exactly as D-03 requires.

Output: `SurveyCarryForward::FIELDS` with the comms-room row gone (and its two private helpers
deleted); `SiteSurveyDocxService::LOGISTICS_KEYS` updated to match (it reads `FIELDS` as a label
source — leaving it unchanged would reference a label key that no longer exists); the PDF header
partial's comms-room table row removed; the four pre-existing tests that currently pin comms room's
presence in these exact files, updated by name to pin its absence instead.
