<objective>
D-02/D-03: decouple comms room from the RAMS generation pipeline — the RAMS hazard/PPE
data builder, the project-context attacher, the DOCX and both PDF RAMS renderers, and the
worksheet's own "Site Logistics" cover-page block. This is the literal "RAMS data feed" named
in 46.8-CONTEXT D-02, which OVERRIDES 46.5 D-03's "keep it everywhere" ruling for comms room only.

⚠️ Research confirmed comms room is PRINTED TEXT ONLY in every one of these six files — no hazard,
PPE, or risk score is keyed on it anywhere in this codebase (grepped). Removing it changes what
prints, not what the RAMS says is safe. Contrast: the "Working Height" field this phase's Plan 04
relocates DOES feed hazard selection — do not confuse the two while working through this plan.

Purpose: stop comms room from reaching any NEWLY generated RAMS/worksheet document, while leaving
the `comms_room_access_status`/`comms_room_access_notes` columns on `SiteSurvey` completely
untouched — no migration, no column drop, existing values stay on disk exactly as they are
(D-03 is a hard STOP on anything that would purge them).

Output: six production files with the comms-room row removed from the text they build; one new
test proving generation still succeeds and a past survey's column values survive unread.
</objective>
