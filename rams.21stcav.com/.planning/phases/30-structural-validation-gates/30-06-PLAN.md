<interfaces>
Hazard row shape (`RamsDataBuilderService.php:440-457`), 10 fixed keys:
  id, hazard, persons_at_risk, pre_likelihood, pre_severity, controls,
  post_likelihood, post_severity, score_reviewed, controls_reviewed, needs_confirmation
Each score is normalised `max(1, min(5, (int) …))` — clamped to 1..5 and **defaulting to 1 when
absent**. That default is a false-positive vector: a row missing `pre_*` gets an initial score of 1
and any populated residual then exceeds it.

Scores are computed at render as `$preL * $preS` and `$postL * $postS`
(`pdf/rams.blade.php:1326-1333`). The reference label is
`'RA' . str_pad($loop->index + 1, 2, '0', STR_PAD_LEFT)` — **row position, not `$h['id']`**.
This is the 260817-r5e correction documented at `RamsComplianceUpgradeService.php:1000-1006` and
mirrored at `DocxBuilderService.php:1221`. Use the index rule or the message names the wrong row.

  Error condition: post_likelihood * post_severity > pre_likelihood * pre_severity
  Warn  condition: post_severity < pre_severity

**The committed golden fixture trips the warn branch today.** `tests/Fixtures/rams/tilda-21cq29531/record.json`
hazard 0, "Working at height for display installation (up to 3m)", is pre 3×4=12, post 1×3=3 —
residual severity 3 below initial severity 4. That is correct, intended output (HAZ-03's aligned
Working-at-Height scoring; `tests/Feature/Rams/WorkingAtHeightResidualScoreTest.php` asserts the
1x4 residual through the live DOCX path). It is the clearest possible evidence that the `s2 < s1`
branch MUST be a warning and MUST NEVER be an error — and it is a ready-made non-vacuity fixture
for the warn path with zero fixture authoring.

Warn entry shape (Plan 30-01's contract):
  ['gate' => 'GATE-04', 'hazard_index' => int, 'hazard' => string, 'message' => string]
`hazard_index` matches `$hIdx` in `review.blade.php:1196`.

UI-SPEC copy:
  warn:  `GATE-04 — {hazard name}: residual severity {s2} is lower than initial severity {s1}.
          Controls reduce likelihood, not severity — confirm this is intended.`
  error: `Hazard "{hazard name}" has a residual score of {post} against an initial score of {pre}.
          Residual risk cannot exceed initial risk — correct the post-control scoring.`
  plus the mandatory tail naming `RAMS_STRUCTURAL_GATES`.
