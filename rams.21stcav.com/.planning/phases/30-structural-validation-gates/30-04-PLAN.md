Data contract (written by Plan 30-01, populated by Plans 30-06 and 30-08):
  generated_data['compliance_warnings'] = [
      ['gate' => 'GATE-04', 'hazard_index' => int|null, 'hazard' => string, 'message' => string],
      ['gate' => 'GATE-14', 'hazard_index' => null, 'step_title' => string, 'hazard' => string,
       'message' => string],
  ]
Always present, always overwritten wholesale, empty by default.

Surface 1 — panel:
  Insert in `review.blade.php` immediately after the `session('error')` block at `:396-398`
  and before the hidden regen form at `:401`. Above the tab wrapper at `:458` so it is visible
  whichever tab is active (the Hazard Register is behind the 5th tab at `:1184`).
  Markup: `.alert .alert-warning` (defined `layouts/app.blade.php:663-673`), `role="status"`.
  NOT `.alert-banner--warning` (`:704`) — that variant carries `.alert-banner__dismiss` (`:688`)
  and this warning is explicitly not dismissible.
  Heading: `⚠ 1 item flagged for review` / `⚠ {N} items flagged for review`.
  Body: `These do not block the document. Check each one before issuing.`
  List: one `<li>` per warning reading `{gate} — {hazard name}: {message}`, 8px gap.
  Empty/absent → render NOTHING. No empty chrome, no "0 warnings", no "All checks passed".
  Precedent for the early-exit: `components/stale-banner.blade.php`'s `@php … return; @endphp`.

Surface 2 — hazard row:
  `review.blade.php:1196` is `@foreach ($hazards as $hIdx => $h)`; the `<tr>` at `:1202` already
  carries `{{ $hazardRowChanged ? 'diff-modified' : '' }}`; the hazard name cell is `:1203`.
  The `@php` block at `:1197-1201` ALREADY computes `$pre`/`$post` with the `?? 1` clamp —
  do not add a second computation (UI-SPEC forbids it); read the warning array instead.
  Add `.gate-flagged` as a sibling rule in the page's own `<style>` block (opened `:420`,
  `.diff-modified` at `:423-425`), using the SAME 3px left rail and 6% `color-mix` tint:
  `border-left: 3px solid var(--warning) !important;` and
  `background: color-mix(in oklab, var(--warning) 6%, var(--surface)) !important;`
  Because the rails are identical, the `⚠` glyph is what makes a flagged row legible —
  render it immediately before the hazard name in the name cell, `aria-hidden="true"`, with
  `title="{gate} — {message}"` on the row. Never render it on a merely diff-modified row.
  A row can be both; gate-flag wins the rail — `.diff-modified` uses `!important` so naive class
  stacking resolves silently by source order. Make the precedence explicit and comment it.
  Matching key: the warning's `hazard_index` against `$hIdx`. If it cannot be resolved, render the
  panel entry only and skip the rail — NEVER guess a row.

Escaping: `{{ }}` everywhere. No `{!! !!}`. The `⚠` is a literal character, not an entity —
raw output is never needed to render it (`review.blade.php:394`, `:397`, `:1203` are the precedent).

Must-not-render boundary: `compliance_warnings` must not appear in
`resources/views/pdf/rams.blade.php`, `resources/views/pdf/rams-v2.blade.php`,
`app/Services/DocxBuilderService.php` or `DocxBuilderServiceV2`. Safe by construction today
(named-key reads only, no generic `@foreach($data as …)` dump) — assert it, do not assume it.
