The DOCX (lines 274-294 of WorksheetDocxService) renders an "ENGINEER WORK SUMMARY" heading for every room, then prefers per-room install-action bullets from `$room['works_summary_bullets']` (rendering them as a PhpWord listBullet), falling back to the prose paragraph at `$room['room_works_description']` when bullets are absent. The show.blade was rendering NEITHER — a user viewing the worksheet on the web saw Equipment → Install Steps → Cable Routes → Power & Network for each room, but no engineer-work-summary block at all, so the canonical web channel diverged from the canonical download channel on the same `generated_data` payload.
