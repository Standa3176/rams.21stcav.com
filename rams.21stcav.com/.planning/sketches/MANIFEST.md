# Sketches

Throwaway HTML mockups for exploring design directions. Not production code.

**Design direction:** bring the RAMS project page toward the clarity of SCC's PMV/callout
drawers — one page, one drawer per required deliverable, traffic lights for status, associated
visits and data filed inside the drawer rather than scattered across separate pages.

**Reference point:** the SCC app (`service.21stcav.com`) PMV + callout drawer pattern.
